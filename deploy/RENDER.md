# الاستضافة التجريبية المجانية على Render

خدمة واحدة (الموقع + الخادم في حاوية واحدة) وقاعدة PostgreSQL مجانية. الإعداد كله في `render.yaml`.

## الخطوات (مرة واحدة)
1. ادخل https://render.com وسجّل بحساب GitHub نفسه (m08ij).
2. **New ← Blueprint** ← اختر المستودع `salam-academy` ← Render يقرأ `render.yaml`.
3. يطلب منك أربع قيم:
   | المفتاح | ماذا تضع |
   |---|---|
   | `SALAM_TRIAL_EMAILS` | البريدات المسموحة مفصولة بفواصل، مثل: `a@x.com,b@y.com,c@z.com` |
   | `SALAM_OWNER_EMAIL` | بريد المالكة (يجب أن يكون ضمن القائمة أعلاه) |
   | `SALAM_OWNER_NAME` | الاسم الظاهر |
   | `SALAM_OWNER_PASSWORD` | كلمة مرور مؤقتة: ١٢ حرفًا أو أكثر، **ولا تحتوي الاسم أو البريد** (وإلا ترفضها سياسة كلمات المرور). تُطلب تغييرها عند أول دخول. |
4. **Apply**. البناء الأول يأخذ ٥–١٠ دقائق. الرابط يكون مثل `https://salam-academy.onrender.com`.

## بعد التشغيل
- المالكة تدخل ← تغيّر كلمة المرور ← «المستخدمون والأدوار» ← «دعوة مستخدم».
- لا يوجد بريد إلكتروني في التجربة: بعد الدعوة يظهر **رابط الدعوة** مع زر نسخ وزر واتساب؛ أرسله للشخص وينشئ كلمة مروره بنفسه.
- إضافة بريد مسموح لاحقًا: Render ← الخدمة ← Environment ← عدّل `SALAM_TRIAL_EMAILS` ← Save (يعيد التشغيل تلقائيًا).
- كل `git push` إلى `main` ينشر نسخة جديدة تلقائيًا.

## حدود الخطة المجانية
- الخدمة **تنام بعد ~١٥ دقيقة** بلا زيارات؛ أول فتح بعدها يأخذ قرابة دقيقة.
- قاعدة البيانات المجانية على Render **تنتهي بعد ٣٠ يومًا** (يمكن ترقيتها أو نقل البيانات قبلها).
- التحقق بخطوتين للفريق مطفأ في التجربة (`SALAM_REQUIRE_STAFF_MFA=false`)؛ يُفعَّل قبل الإطلاق.

## إن لم يُنشأ حساب المالكة
افتح Render ← الخدمة ← **Logs** وابحث عن `SALAM_OWNER_PASSWORD rejected` أو `No owner yet`، صحّح القيمة في Environment ثم **Manual Deploy**.
